AI-Powered Image Analysis Web App

A full-stack application that uses Clarifai’s General Image Concept Model to generate detailed, multi-word tags (e.g., “red sports car,” “sunset beach”) from user-uploaded images. This allows users to extract meaningful insights and descriptions from visual content.

Anonymous Next.Js Messaging Web App

A secure, full-stack application that allows users to send messages anonymously to other users with receiving user's unique link. Built with Next.js for server-side rendering and dynamic site generation, the app delivers fast performance while maintaining a responsive, accessible UI across devices.

The platform integrates NextAuth for authentication, MongoDB with Mongoose for secure data storage, and OpenAI for auto-generating messages, enhancing user engagement. TypeScript, React Hooks, Tailwind CSS, shadcn/ui, and Zod ensure maintainable, type-safe code and robust input validation.
